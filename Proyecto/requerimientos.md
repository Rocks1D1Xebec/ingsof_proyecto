**Requerimientos**
1. El sistema permitirá al usuario crear una cuenta y registrarse.
2. El sistema permitirá al estudiante iniciar y cerrar sesión.
3. El sistema permitirá al estudiante elegir la materia que desea consultar.
4. El sistema permitirá al estudiante enviar preguntas sobre un tema.
5. El sistema responderá las preguntas del estudiante con explicaciones aclaratorias.
6. El sistema explicará los temas paso a paso.
7. El sistema generará ejercicios de práctica sobre los temas estudiados.
8. El sistema revisará las respuestas enviadas por el estudiante.
9. El sistema señalará los errores del estudiante y mostrará la respuesta correcta.
10. El sistema adaptará las explicaciones y ejercicios al nivel de cada estudiante.
11. El sistema guardará el progreso de cada estudiante.
12. El sistema cubrirá las materias de Matemáticas, Física, Lenguaje y Química.
13. El sistema estará disponible en cualquier momento, sin restricción de horario.
14. El sistema funcionará correctamente desde un celular.
15. El sistema deberá ser fácil de usar para personas sin conocimientos de tecnología.
16. El sistema deberá responder rápidamente a las consultas del estudiante.
17. El sistema protegerá la información de los usuarios.
18. El sistema soportará múltiples usuarios al mismo tiempo.
19. El sistema adaptará la forma de explicar según la técnica de estudio de cada estudiante, por ejemplo aprender por asociación con temas de su interés.
