**Requerimientos esenciales**
- El sistema permitirá al usuario crear una cuenta y registrarse.
- El sistema permitirá al estudiante iniciar y cerrar sesión.
- El sistema permitirá al estudiante elegir la materia que desea consultar.
- El sistema permitirá al estudiante enviar preguntas sobre un tema.
- El sistema responderá las preguntas del estudiante con explicaciones aclaratorias.
- El sistema explicará los temas paso a paso.
- El sistema generará ejercicios de práctica sobre los temas estudiados.
- El sistema revisará las respuestas enviadas por el estudiante.
- El sistema señalará los errores del estudiante y mostrará la respuesta correcta.
- El sistema cubrirá las materias de Matemáticas, Física, Lenguaje y Química.
- El sistema estará disponible en cualquier momento, sin restricción de horario.
- El sistema funcionará correctamente desde un celular.
- El sistema deberá ser fácil de usar para personas sin conocimientos de tecnología.

**No tan esenciales**
- El sistema adaptará las explicaciones y ejercicios al nivel de cada estudiante.
- El sistema adaptará las explicaciones según la técnica de estudio de cada estudiante (por ejemplo, aprender por asociación con temas de su interés).
- El sistema guardará el progreso de cada estudiante.
- El sistema deberá responder rápidamente a las consultas del estudiante.
- El sistema protegerá la información de los usuarios.

**No esenciales**
- El sistema soportará múltiples usuarios al mismo tiempo.

**Preguntas**

1. ¿Cuáles son indispensables para la primera versión?
Los requerimientos del bloque Esenciales, porque sin ellos no se cumple el objetivo principal: que el estudiante pueda resolver sus dudas y aprender con el asistente desde su celular. La primera versión debe concentrarse en: cuenta de usuario, elegir materia, hacer preguntas, explicaciones paso a paso, ejercicios, revisión de errores y funcionamiento en celular.

2. ¿Cuáles pueden esperar?
Los de los bloques No tan esenciales y No esenciales:
- Adaptar el contenido al nivel de cada estudiante.
- Adaptar las explicaciones a la técnica de estudio de cada estudiante.
- Guardar el progreso.
- Múltiples usuarios al mismo tiempo.
- Seguridad avanzada de la información.
Son mejoras que aportan comodidad, pero no impiden usar la función básica del asistente.

3. ¿Qué funcionalidades forman el núcleo del sistema?
Las del bloque Esenciales, principalmente:
- Elegir una materia.
- Enviar preguntas y recibir explicaciones.
- Explicar los temas paso a paso.
- Generar ejercicios y revisar los errores.
- Funcionar desde el celular.

4. ¿Qué funcionalidades son complementarias?
Las de los bloques No tan esenciales y No esenciales, ya que agregan comodidad o personalización pero no son necesarias para el uso principal del sistema.

7. Plan de requisitos para la primera versión.
Primera versión: registro e inicio de sesión, elegir materia, enviar preguntas, recibir respuestas aclaratorias, explicaciones paso a paso, generación de ejercicios, revisión de respuestas con indicación de errores, disponibilidad en cualquier momento, funcionamiento en celular y facilidad de uso.
Versiones siguientes: adaptación del contenido al nivel de cada estudiante, adaptación a la técnica de estudio de cada estudiante, guardado de progreso, soporte de múltiples usuarios y protección avanzada de la información.
