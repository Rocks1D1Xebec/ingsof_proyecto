**Necesidades identificadas**
1. Necesita que sus hijos puedan sacarse las dudas que tengan sobre los temas.
2. Necesita que el asistente explique los temas paso a paso.
3. Necesita que el asistente responda las preguntas de los estudiantes.
4. Necesita que el asistente genere ejercicios para practicar.
5. Necesita que el asistente evalúe las respuestas y les indique sus errores.
6. Necesita que las explicaciones se adapten al nivel de cada hijo.
7. Necesita que el asistente ayude con varias materias.
8. Necesita que el sistema esté disponible en cualquier momento.
9. Necesita que los hijos aprendan a solucionar por sí mismos con las explicaciones del asistente.
10. Necesita que el sistema funcione desde un celular, ya que no cuentan con computadora.
11. Necesita que el asistente se adapte a la técnica de estudio de cada estudiante (por ejemplo, aprender por asociación con temas de su interés).

**Requisitos**
1. El sistema permitirá al estudiante realizar preguntas y recibir respuestas aclaratorias.
2. El sistema explicará los temas paso a paso.
3. El sistema generará ejercicios de práctica sobre los temas estudiados.
4. El sistema evaluará las respuestas del estudiante y le mostrará sus errores.
5. El sistema adaptará las explicaciones y ejercicios según el nivel de cada estudiante.
6. El sistema cubrirá varias materias (Matemáticas, Física, Lenguaje y Química).
7. El sistema estará disponible en cualquier momento y sin restricción de horario.
8. El sistema será accesible desde un celular mediante el navegador.
9. El sistema adaptará la forma de explicar según la técnica de estudio de cada estudiante (por ejemplo, aprender por asociación con temas de su interés).
